-> 100 Days of DSA in C

Welcome to my 100 Days of Data Structures and Algorithms (DSA) in C challenge!
This repository documents my daily progress, consistency, and learning as I strengthen my problem-solving skills using the C programming language.

-> About the Challenge

The goal of this challenge is to:

Build a strong foundation in Data Structures & Algorithms

Improve logical thinking and coding efficiency

Practice daily problem-solving with discipline and consistency

Prepare for placements, competitive programming, and interviews

I will solve at least one DSA problem every day for 100 days, starting from basics and gradually moving to advanced topics.
